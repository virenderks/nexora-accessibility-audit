
# NEXORA Insights – Accessibility Audit Report

## 1. Project Overview

NEXORA Insights is a responsive technology blog website built using HTML5 and CSS3. The main objective of this project was to improve website accessibility and user experience.

## 2. Accessibility Improvements

### Semantic HTML

Used semantic elements such as header, nav, main, section, article and footer to create a meaningful page structure.

### Skip Navigation

Added a Skip to main content link to help keyboard users bypass navigation.

### Keyboard Accessibility

Added visible focus outlines so users can identify focused links while navigating with the keyboard.

### Colour Contrast

Improved the focus outline colour from #D97706 to #B45309 for better visibility.

### Responsive Design

Used CSS media queries to make the website work on mobile and desktop screens.

### Reduced Motion

Added a prefers-reduced-motion CSS rule for users who prefer less animation.

## 3. Accessibility Testing Results

| Test | Result |
| --- | --- |
| Lighthouse Accessibility | 100/100 |
| Skip link test | Passed |
| Keyboard navigation | Passed |
| Visible focus outline | Passed |
| Mobile layout | Passed |
| 200% browser zoom | Passed |

## 4. Benefits

These improvements make the website easier to navigate for keyboard users, improve readability, support smaller screens and provide a better experience for users with different accessibility needs.

## 5. Conclusion

The accessibility audit helped identify and improve important areas of the website. The final Lighthouse Accessibility score was 100/100. Manual keyboard, mobile and zoom tests also passed.
