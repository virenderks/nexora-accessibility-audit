# NEXORA Insights – Accessibility Audit

A responsive technology blog website developed using HTML5 and CSS3, with a focus on accessibility and user experience.

## Features

- Semantic HTML structure
- Skip to main content link
- Keyboard-friendly navigation
- Visible keyboard focus indicators
- Improved focus colour contrast
- Responsive mobile layout
- Reduced motion support

## Accessibility Testing

- Lighthouse Accessibility Score: 100/100
- Keyboard navigation: Passed
- Skip link: Passed
- Mobile layout: Passed
- 200% browser zoom: Passed

## Technologies Used

- HTML5
- CSS3
- JavaScript (not required for the implemented features)
